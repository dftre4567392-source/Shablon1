## Технические требования к интеграции
1. Не обходить серверную проверку Telegram initData и роли мастера.
2. Не нарушать эксклюзивность бронирования и блокировку дней.
3. Не смешивать данные разных мастеров.
4. Добавить миграции PostgreSQL при необходимости.
5. Защитить новые API и протестировать основные сценарии.
6. По умолчанию не добавлять платежи или рекламу.
7. Оставить настраиваемую тему заказчика.
