# BOOKCORE — папка для передачи на доработку

Заполни `АНКЕТА_МАСТЕРА.md` при создании нового проекта.
Если нужен дополнительный функционал, заполни `ЗАПРОС_НОВОГО_МОДУЛЯ.md`.

Отправляй эти файлы вместе с актуальными исходниками `bookcore-vercel/index.html`, `bookcore-vercel/api/handler.ts` и ссылкой на GitHub.

Рабочий веб-адрес Vercel: https://bookcore-telegram.vercel.app

Секреты Telegram и хранилища никогда не пересылать в этом архиве. Для их установки используется Vercel → Project Settings → Environment Variables.

В текущем компактном MVP один мастер, Vercel Functions и приватный Vercel Blob. При масштабировании потребуется транзакционная база данных и отдельная система напоминаний.
