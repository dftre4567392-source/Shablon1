# BOOKCORE — Telegram Mini App / Vercel

**Рабочая версия:** https://bookcore-telegram.vercel.app  
**Витрина:** https://bookcore-telegram.vercel.app/showcase.html

## Что реализовано
- Клиент: выбор до 6 услуг, суммирование цены и длительности, календарь 45 дней, свободные слоты, запись, отмена, перенос, профиль с Telegram-аватаром.
- Мастер: обзор, календарь, ручные записи, управление услугами и графиком, блокировки, список клиентов, изменение статусов.
- Несколько разрешённых Telegram ID мастеров в **одной** студии (это не многоклиентская SaaS-система).
- Telegram webhook и уведомления; защита по проверенным `initData` на сервере.
- Хранение данных в приватном Vercel Blob с защитой от конкурентной перезаписи по ETag.

## Структура
- `index.html`: клиентская и мастерская части.
- `api/handler.ts`: Vercel API / Telegram.
- `scripts/check-syntax.mjs`: проверка JS без внешних инструментов.
- `tests/`: изолированные тесты API и UI, плюс Chromium E2E.
- `customer-template/`: анкета и шаблон новой установки.
- `QA_REPORT.md`: таблица проверок и эксплуатационные ограничения.

## Проверка
```bash
cd bookcore-vercel
npm run check
npm test
```

Chromium E2E запускается через GitHub Actions `.github/workflows/bookcore-browser-e2e.yml`. Для локального запуска требуется Playwright/Chromium.

## Настройка новой студии

Создайте **отдельный проект Vercel, отдельного Telegram-бота и отдельное хранилище** (или по крайней мере отдельный путь внутри приватного Blob). Путь существующего боевого BOOKCORE не менять.

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Новый токен бота; только в защищённых переменных хостинга |
| `MASTER_TELEGRAM_ID` | Главный аккаунт мастера |
| `ADDITIONAL_MASTER_TELEGRAM_IDS` | Дополнительные ID через запятую, при необходимости |
| `TELEGRAM_WEBHOOK_SECRET` | Секрет входящего Telegram webhook |
| `APP_URL` | HTTPS URL нового Mini App |
| `BLOB_READ_WRITE_TOKEN` | Приватное Blob-хранилище |
| `BOOKCORE_STORAGE_PATH` | Уникальный путь данных, например `bookcore/customers/nails-001/state.json` |
| `BOOKCORE_SERVICES_JSON` | JSON-массив начального каталога услуг (1–30 услуг, цена и длительность) |
| `TENANT_DISPLAY_NAME` | Название студии |
| `MASTER_DISPLAY_NAME` | Отображаемое имя мастера |
| `TENANT_TIMEZONE` | Часовой пояс IANA, например `Asia/Barnaul` |
| `TENANT_ACCENT_COLOR` | Акцент цвета в формате `#734B67` |

**Важное поведение:** `BOOKCORE_SERVICES_JSON` используется **только при первом создании пустой базы**. Для уже работающей студии каталог управляется через кабинет мастера. Никогда не меняйте `BOOKCORE_STORAGE_PATH` существующего клиента без плана миграции: это создаст новый пустой набор записей, а не перенесёт прежний.

Пакеты примеров и конфигураций для нового клиента передаются отдельно. Исходный продакшен по умолчанию использует `bookcore/v1/state.json`, поэтому обновление не меняет существующие записи.

## Ограничения

Компактная Vercel-версия предназначена для небольшой студии. Она **не является готовой многоклиентской SaaS-платформой**: нет транзакционной PostgreSQL, автоматического экспорта данных, восстановления из резервной копии, нагрузочного SLO, автоматических напоминаний по времени и интеграции MAX. Для коммерческого масштабирования нужны отдельные этапы разработки, юридическая проверка обработки персональных данных и реальная Telegram-приёмка.
