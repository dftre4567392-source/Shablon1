# BOOKCORE Studio — клиентская витрина

Публичная интерактивная демонстрация Telegram Mini Apps, клиентского кабинета и панели мастера.

**Витрина (production):** https://bookcore-showcase.vercel.app
**Рабочая веб-версия BOOKCORE:** https://bookcore-telegram.vercel.app
**Telegram-бот:** https://t.me/Shablon1py_bot

## Что показываем
- BOOKCORE: реально опубликованная компактная веб-версия онлайн-записи.
- BEAUTY / TATTOO / WELLNESS: переключаемые примеры дизайна с демонстрационными данными.
- Интерфейс клиента: выбор услуги, даты и времени.
- Интерфейс мастера: показатели, календарь, список записей, услуги и клиенты (демо).
- AI-сервисы и агенты: направление в разработке, не выдаётся за готовое внедрение.
- Функции, этапы работы и формирование текста заявки без отправки личных данных на сервер.

## Как отправить клиенту
Передайте один публичный URL витрины. Клиент может попробовать переключение ролей и отраслей, затем скопировать заявку или поделиться ею через Telegram.

## Ограничения
Это отдельная **демо-витрина**, она не создаёт реальные записи и не содержит активной формы сбора контактов.
Цена и сроки не заявляются без технического задания; примеры цен в экранах демонстрационные.
Оплата внутри BOOKCORE в базовой версии не реализована.

## Проверки
Браузерные тесты на Chromium (desktop и iPhone-профиль): переключение ролей, ниш, вкладок и демо-записи — пройдены. Смотреть GitHub Actions: `.github/workflows/bookcore-showcase-browser.yml`.
